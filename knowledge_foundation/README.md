## Claim ID convention

`PM-` price movement · `SW-` swings/waves · `MS-` structure · `LQ-` liquidity · `FZ-` FVG/OB/zones · `MR-` multiscale reasoning · `LL-` learning · `CH-` chart cases · `OS-` open source/academic · `CF-` conflicts · `IC-` implementation contracts · `SRC-` sources.

Every claim that affects a selection carries: claim type (A–H, see file 00), evidence grade, source ID(s), scope, limitations, and related/conflicting claims. The full list is in `claims_index.json`.
