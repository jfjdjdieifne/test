# جارفس بصوت «بشر حقيقي» — ElevenLabs (الدليل الكامل من الصفر)

> ليش؟ Edge TTS **ما فيه وقفات حقيقية ولا «اممم» ولا تفكير بصوت عالي** — هو ينطق الجملة وين صار نصها، بس ما بيتنفس زي البني آدم.
> ElevenLabs (Eleven v4 / v4 Turbo) حالياً **الأقوى في العربي** بتعادل Leaderboards المستقلة — يلتقط النبرة الشامية/الخليجية/المصرية من نص الجملة، ويدعم [audio tags] مثل `[sighs]` عبر v3/v4.

## ⚠️ الحقائق من البداية (بدون تجميل)
1. **ما في شي خارق 100% مجاناً.** الحصة المجانية (10,000 حرف/شهر ≈ 15–20 دقيقة مكالمة) تكفي **لتجرب وتتأكد من الجودة** قبل أي دفعة.
2. للراحة اليومية: أرخص خطة بتكفي **Starter — $6/شهر** (150k حرف Flash/Turbo ≈ مئات الردود). Creator ($22) مضاعفة. **الدفع ببطاقتك أنت، ما بدفع عنك ولا بسجل بحسابك.**
3. **AWS Nova Sonic ما بيحكي عربي** (إنجليزي/فرنسي/ألماني/إسباني/إيطالي فقط — والنسخة 2.5 سبعة لغات بلا عربي). فـ«كل شي من حساب AWS» = Polly فقط، وجودتها أقل من Edge بكثير بالتعبير.
4. **ما في إنسان Syrian-native Neural مدفوع ناضج** لحد هلق — الأقرب: Eleven v4 مع **نص شامي** (اللهجة بتطلع من النص مو من الصوت) — النتيجة عادة ممتازة.

## الخطوات (15 دقيقة، مرة واحدة)
### 1) افتح حسابك
1. روح [elevenlabs.io](https://elevenlabs.io) → **Sign up** (إيميلك العادي — الحساب المجاني **بدون بطاقة**).
2. من اللوحة: **Developers → API Keys → Create API Key** → انسخ المفتاح (`sk_...`) — ما تشاركه ولا تحطه Git.

### 2) جرّب الصوت قبل الدفع (الحصة المجانية)
1. من اللوحة: **Voice Library** → ابحث `Arabic` → فلتر **Language: Arabic**.
2. كليك على صوت عاجبك (جرّب مذكر شامي أو خليجي) → اسمع **Preview** → **Use voice** → من صفحة الصوت انسخ **Voice ID** (على اليمين).
3. عايز صوتك أنت أو صوت «دكتور» معين؟ **Voice Cloning**: ارفع 3–5 دقائق تسجيل نظيف → instant clone (مجاني ضمن خطتك).

### 3) على السيرفر (EC2) — أضف 3 متغيرات لنفس ملف الخدمة
```bash
sudo nano /etc/systemd/system/jarvis-live.service
```
أضف تحت [Service] Environment= السطرين هدول (عدّل القيم):
```
Environment=JARVIS_TTS=elevenlabs
Environment=ELEVENLABS_API_KEY=sk_...
Environment=ELEVENLABS_VOICE_ID=xxxxxxxxxxxxxxxxxxxx
# اختياري (الافتراضي eleven_v4_turbo — الأسرع ~150ms):
# Environment=ELEVENLABS_MODEL=eleven_v4   # أقصى تعبير — أبطأ شوي (مش Streaming full)
```
ثم:
```bash
sudo systemctl daemon-reload && sudo systemctl restart jarvis-live
journalctl -u jarvis-live -f   # شوف «ElevenLabs TTS: model=…» بالسطور الأولى
```

### 4) جرب المكالمة
افتح `https://<worker>/live` → **اتصل بجارفس لايف**.
- اطلب منه يحكيك عن يومك — رح تسمع: «اممم… خليني أفكر…» والوقفات الطبيعية.
- إذا ما حسيت إن فيه فرق كبير، جرب صوت تاني من Voice Library (الفرق الأكبر دايماً بالصوت المختار، مش بالموديل).

## ملاحظات صادقة
- **الأداء**: eleven_v4_turbo ≈ 150ms TTFA (مناسب للمكالمة الحية). `eleven_v4` أقصى تعبير بس أبطأ — للبودكاست/التسجيلات، مش للمقاطعة الحية.
- **كسر الحصّة**: خلصت المجانية؟ البوت يرجع خطأ واضح، وتقدر دايماً ترجع `JARVIS_TTS=polly` أو `edge` بنفس الملف.
- **المفتاح**: `sk_...` هون على السيرفر فقط — **لا تُرسله لأي محادثة ولا تحطه Git**.
- **الجودة القصوى**: أفضل تركيبة فعلية = **نص شامي حقيقي** (التعليمات المعدلة بالـ Agent هلق بتعطيه «اممم…» و«يلا…» والوقفات) **+ صوت مختار جيداً** + v4 Turbo.
