# جارفس بصوت Gemini Flash TTS — الدليل الكامل من الصفر (مجاني ومتجدد)

> ليش هالمسار؟ صوت Gemini Flash TTS (من Google) حالياً **أقرب شيء لأداء ElevenLabs بالعربية**، مع ميزة ما لإله غيره: **«Director's Notes»** — تكلمله بالكلام العادي شو بدك بالظبط («احكِ بلهجة دمشقية دافئة مع وقفات طبيعية وتفكير بصوت عالي») وهو **ينفذها**. والأهم: **مجاني، بدون بطاقة، ويتجدد يومياً.**

## ١) شو اللي بيشتغل فعلياً بعد هالخطوة

```
أنت ──► /live (متصفحك) ──► LiveKit Cloud ──► EC2 (السيرفر — Agent جارفس)
                                                │
        صوتك يتحول لنص: Groq Whisper (مجاني) ◄──┤
        الرد بيتولد بالعقل: Coarena Claude (مجاني) ◄──┤
        النص يتحول لصوت: **Gemini Flash TTS (مجاني، متجدد يومياً)** ◄──┤
        فشل Gemini؟ → يرجع **تلقائياً** لـ Edge ar-SY (مجاني بلا حدود) ──┘
```
**ملاحظة مهمة جداً عن AWS:** أمازون **لسا إلها دور كامل** — هي بيت التشغيل اللي Agent جارفس شغال عليه 24/7 (استقبال المكالمات + Whisper + العقل بانتظارك). Gemini هو فقط «الحنجرة» من بره الحساب. (وPolly ar-AE تضل خيار احتياطي داخل حسابك AWS.)

## ١) جيب مفتاح Gemini (3 دقائق، من المتصفح، بلا بطاقة)

1. افتح **[https://aistudio.google.com/apikey](https://aistudio.google.com/apikey)** وسجل دخول بحساب Google (حسابك الأساسي أو ثانوي).
2. اضغط **Create API key** ← اختار «Create API key in new project» (أو مشروعك الحالي — نفس الحصَّة بالنهاية).
3. انسخ المفتاح (يبدأ عادة بـ `AIza...`). **لا تحطو بأي محادثة ولا بـ Git.**
4. **فعّل النموذج الصوتي:** أول استخدام لـ TTS أحياناً يطلب **Enable** لواجهة (Generative Language API) — بتوافق بضغطة.

## ٣) اختبار الصوت قبل أي شي (10 ثوانٍ من جوجل نفسها)

بجهازك/جوالك افتح: <https://aistudio.google.com/prompts/new_chat> ← جرّب النموذج `gemini-3.1-flash-tts-preview` مع أي جملة عربية واسمع. على قناعتي — الصوت ناس مع «اممم» والوقفات.

> تحقق محلي من اسم النماذج المتاحة لك:
> ```bash
> curl "https://generativelanguage.googleapis.com/v1beta/models?key=ضع_مفتاحك" | grep -o '"name": *"models/[^"]*tts[^"]*"'
> ```
> إذا ظهر اسم مختلف بدل `gemini-3.1-flash-tts-preview` — بدّله بمتغير `GEMINI_TTS_MODEL`.

## ٤) كم «تكفي» كل مفتاح؟ (الأرقام الحقيقية بصراحة)

| البند | القيمة (حتى 2026-11) |
|---|---|
| الكوتا اليومية (تقارير موثقة، جوجل ما تنشر جدول رسمي) | **~100 طلب/يوم** لنماذج Flash TTS |
| الحد بالدقيقة | **~3 طلبات/دقيقة** (أرقام متغيرات من حسابي AI Studio — شوفها من صفحة Rate Limits بحسابك) |
| متى تتجدد | منتصف الليل **بتوقيت المحيط الهادئ** (~08:00 أو 09:00 بتوقيت لبنان بحسب التوقيت الصيفي) |
| كل رد من جارفس = كم طلب؟ | **طلب واحد** (جملة قصيرة) → مفتاح واحد يكفي نظرياً حتى ~100 رد/يوم |
| حساب شهري تقريبي | 100 رد × 30 يوم = **حتى 3,000 رد/شهر مجاني** — يفوق استعمالك الشخصي بكثير |
| إذا طارت الكوتا؟ | **يرجع Edge ar-SY تلقائياً** (GRACEFUL) — البوت ما بيموت أبداً (JARVIS_TTS يظل gemini مع سقوط حر) |

## ٥) «بدي مفاتيح زيادة» — الطرق القانونية الصريحة ⚠️

**أولاً وقبل كل شي — فكّر بـ Honest:** الحساب الواحد يكفيك **٩٠٪ من الأحيان**: أنت 3-5 مكالمات يومياً = 3-5×(2-3) طلبات ≪ 100. لا تحتاج فوراً أي شيء.

**ثانياً — ما تسوّيه أبداً:** فتح حسابات Google وهمية بالتتابع لتخطي الكوتا. هذا **خرق صريح لشروط Google**، والمفاتيح بتتنحضر — وعادة ما تسترجع حسابك بدون استئناف. أنا ما ببني شيء على أساس كسر الشروط.

**المسالك القانونية للتوسعة:**
1. **Projects مختلفة داخل نفس حسابك Google** ← كل مشروع حصته منفصلة شرعياً (تأكد من الشروط الحالية بمركز مساعدة AI Studio؛ هيدا الحل الأقرب).
2. **طلب رفع الكوتا مجاناً!** من [AI Studio → Rate Limits](https://aistudio.google.com/) أو Google Cloud Console → IAM & Admin → Quotas → ابحث عن نماذج TTS → **Request increase**. جوجل غالباً توافق للأفراد — هذا **مجاني رسمياً**.
3. **Pay-as-you-go** (اختياري ولاحقاً فقط): نماذج Flash TTS رخيصة جداً (سنتات بالدقيقة — ما بتغطي أكثر من بضعة دولارات شهرياً للاستخدام الشخصي)، والفائدة: **لا طخة كوتا ولا خوف**.
4. **قص أصوات إضافية مجانية من مزودين اصدق:** Microsoft (Edge — لا حدود)، Google Cloud TTS (1M حرف WaveNet/شهر **للأبد**)، ElevenLabs مجاني (10k حرف/شهر للأبد)، Groq `playai-tts-arabic` (~100 طلب/يوم)، Azure F0 (500k حرف/شهر) — **مجمّعة من عدة مزودين مختلفين = تستوعب عدد لا نهائي من الطلبات مجاناً وبشكل قانون تماماً لأن كل جهة حصتها مستقلة.** (هذي **ليست** «مفاتيح وهمية» — هذي الطريقة الوحيدة الشرعية لـ«مفاتيح كتيره».)

### متى تستخدم مفاتيح متعددة بمجمّع `GEMINI_TTS_API_KEYS`؟
فقط عندما تنتقل لمسار المدفوع أو لمشاريع متعددة تملكها رسمياً، لأن مفاتيح نفس المشروع **تتقاسم نفس الحصة اليومية**. التنفيذ يدعمك تلقائياً:
```bash
export GEMINI_TTS_API_KEYS="AIzaS...الأول,AIza...الثاني,AIza...الثالث"
```
المجمّع يدير: توزيع round-robin → عند 429 (خلصت الحصة) يضع المفتاح بالـ **Cooldown 5 دقائق** → عند 403/موت المفتاح Cooldown ساعة → يطبع بالمفاتيح **آخر 4 أحرف فقط** (سجلات نظيفة أبداً) → لو الكل استيفى: يرجع Edge تلقائياً.

## ٦) التشغيل على السيرفر (EC2) — 4 أوامر، 5 دقائق

```bash
# الآن على السيرفر (أو أول ما تشغله مستقبلاً):
cd ~/test/agency-cloudflare/livekit-agent        # أو المسار عندك
git pull
pip install -r requirements.txt             # ما بدك إلا LiveKit plugin الحالي — ما ضايف أي شيء جديد
# أضف بجانب تعريفات الـ service (مجلد /etc/systemd/system/jarvis-live.service):
# Environment=JARVIS_TTS=gemini
# Environment=GEMINI_TTS_API_KEYS=AIza...المفتاحك(.Key) # واحد بس كافٍ؛ أكثر من هذا اختياري
sudo systemctl daemon-reload
sudo systemctl restart jarvis-live
journalctl -u jarvis-live -f                 # أول سطر لازم يكون: «Gemini TTS» أو سجلات LiveKit
```
ثم افتح `https://<worker-url>/live` واضغط **اتصل بجارفس لايف** — رح تسمع جملة ترحيب الصوت «اممم… يا هلا دكتور» بنبرة بشرية.

## ٧) ضبط اللحن بالضبط كيف بدك (كل القيم بـ env)

| المتغير | الافتراضي | شو تعمل عليه |
|---|---|---|
| `GEMINI_TTS_VOICE` | `Charon` (هادي، وقور الذكور) | جرّب `Puck` (حيوي)، `Fenrir` (قوي)، `Kore` (أنثى)، `Aoede` (دافئة)، `Algieba` (ناعمة) |
| `GEMINI_TTS_ACCENT` | Levantine Shami (Damascus) | غيّرها بدّالها: `Saudi Gulf (Riyadh)`، `Egyptian (Cairo)`… |
| `GEMINI_TTS_STYLE` | warm, unhurried, thinks out loud | اكتب بأي لغة — جرب: `«_Ground-level friend from Damascus telling a story — natural hesitations, «اممم», warm laughter»` |
| `GEMINI_TTS_MODEL` | `gemini-3.1-flash-tts-preview` | غيّرلا داعي إلا الاسم تغير بالمستقبل |
| `GEMINI_TTS_FALLBACK_EDGE` | `1` | إذا بدك الفشل يرجع خطأ بدل الصوت الاحتياطي: `0` |

> ملاحظة صريحة: الصوت نفسه (30+ prebuilt) **ما هو سوري أصلي** — اللحنة الشامية تطلع من **Director's Notes + نص جارفس الشامي** اللي صار هلق مكتوب بجمل قصيرة بوقفات. النتيجة بالممارسة ممتازة بمعظم الأحيان.

## ٨) حدود صادقة ولا جمل مجاملة

1. الحصة **مو مضمونة للأبد** — ممكن تُعدل/تنقص/تزول (هي Preview حالياً). لو احتجت إحساس «ببا انه مرصوص»: استخدم المسار المدفوع (بنت فلة) أو Groq/WaveNet (المجاني الدائم).
2. **الكوتا لكل مشروع** — مفاتيح نفس المشروع ما بتنفع شيء (نفس الـ 100 طلب).
3. **Gemini بترجع بطء نسبي** (~1–3 ثوانٍ قبل أول صوت) — أبطأ من ElevenLabs Turbo الحقيقية (150ms) لكنه **خارق عليها بالحساسية والوزن**.
4. بياناتك (الصوت/المحادثة) بالطبقة المجانية **ممكن تُستخدم لتحسين نماذج Google** — إذا عندك أسرار حقيقية لا تحكيها بالصوت هلق.
5. **الأمان:** المفاتيح خلف env variables بس — **أبداً** لا تلصقها بـ git ولا بأي محادثة؛ لو انخرطت، دور/استدعها فوراً.

## ٩) لما تجرب وتعجبك — بعدين نقرر بالتفصيل

1. **«حلوكتير، بدي كمل فيه»** → مفتاح واحد يظل يشغلك؛ ولا فعل ثاني مطلوب منك الآن.
2. **«بدي أكثر + أكثر لساعات طويلة»** → إما طلب زيادة الكوتا مجاناً (الخطوة 5/2) أو انتقل لـ Pay-as-you-go (سنتات) أو قولي نبني Route متعددة بنِسبة مماثلة (Gemini + Edge + WaveNet).
3. **«حسيت فيه شوي بطء/تحب...»** → نفس v4 الجديد من ElevenLabs (الكود مدموج جاهز — `ELEVENLABS_SETUP_AR.md`).
