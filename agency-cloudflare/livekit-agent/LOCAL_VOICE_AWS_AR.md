> ⚠️ لا تنسخ أي سر أو مفتاح لهذا الملف — الإعدادات الحقيقية ب `[vars]` أو بملف الخدمة على السيرفر فقط.

## 1) شو الحقيقة عن "هرمس" (Hermes) — قبل ما تتحمس 🤔

«هرمس» (Nous Research **Hermes 3 / Hermes 4**) مو ESC/إطار سحري — هو **نموذج لغوي مفتوح الأوزان**، وممتاز عن نفسه بس عند توفر العتاد:

| الحجم | الـ RAM/VRAM المطلوبة (Q4) | وين بيقدر يشتغل |
|---|---|---|
| Hermes 3 8B (GGUF ~4.9GB) | ~6GB VRAM أو RAM | GPU شخصي/لابتوب قوي — **ليس** EC2 مجاني (t4g.micro = 1GB) |
| Hermes 3 70B | ~40GB+ VRAM | GPU باهظ — خارج الرصيد تماماً |
| Hermes 4 405B | ~240GB | خارج البحث أصلاً |

**الحسبة على AWS المجاني (t4g.micro، 1GB RAM، بدون GPU):** تشغيل Hermes محلياً على نفس السيرفر = **مستحيل**. حتى على t4g.small (2GB). ومافي GPU مجاني بهذا الرصيد إطلاقاً.

### فإذا بدك هرمس فعلاً — الطريق مشروع:
1. **عبر API مجاني**: Nous Hermes متاح عبر OpenRouter (النماذج المجانية المتوفرة تتقلب حسب الوقت). تجربته صفر كلفة وبـ **صفر كود** — لأن `agent.py` بيقبل أي Endpoint مطابق لـ OpenAI:
   ```bash
   # بالمكان بدل COARENA_BASE_URL/COARENA_MODEL (ملف الخدمة على السيرفر):
   Environment=COARENA_BASE_URL=https://openrouter.ai/api/v1
   Environment=COARENA_API_KEY=ضع_مفتاح_OpenRouter_هون
   Environment=COARENA_MODEL=nousresearch/hermes-3-llama-3.1-70b:free
   ```
   ⚠️ التوافر والجودة يتغيران يومياً بالراوتر المجاني — إذا اختفى الموديل بيتحول الطلب عندهم لموديل تاني مجاني، مو مشكلة توقف.
2. **محلياً على جهازك الشخصي ب GPU 8GB+** (Ollama): `ollama pull hermes3:8b` ثم نفس تغيير المتغيرات مع `http://localhost:11434/v1`. مجاني 100% — طبعاً اللاب توب يضل شغال.
3. **Hermes Agent (إطار Nous للـ agents)** — إذا تقصد الإطار نفسه: هو حر تحت رخصة MIT، بس بيشتغل فوق موديل — والموديل هو المشكلة، مو الإطار. نفس القيود أعلاه تسري.

**توصية صريحة:** Coarena (Claude Fable 5.2) يضل العقل الأساسي — **مجاني $5/يوم حتى بدون AWS أصلاً** (ما بتنتهي صلاحيته بانتهاء رصيد AWS!). Hermes = احتياط تجريبي ب `COARENA_MODEL` تغيير، ما تنزل تحت مستوى Fable 5.2 اليوم. ولا تحرق الرصيد على RunPod/GPU بتجريب هرمس — الرصيد لتشغيل الهرفيس-الجهاز (Agent) مش للعقول.

## 2) "صوت محلي يشبه ElevenLabs" — كل الخيارات على الطاولة (2026-11-13)

**الحقيقة الأولى:** لا يوجد اليوم صوت عربي + محلي 100% + مجاني + جودة ElevenLabs كاملة على خادم 1GB. اللي موجود تقاطع ذكي:

| الحل | عربي؟ | محلي على EC2؟ | الجودة | الكلفة/السرعة | الحكم |
|---|---|---|---|---|---|
| **Edge TTS `ar-SY-LaithNeural` (الحالي بالبوت والـ Agent)** | ✅ شامي ممتاز | ❌ سحابي (لكن مجاني وبلا مفتاح) | بشرية، يتنفس ويقف | <1ث للجملة · **بلا حدود** | **الافتراضي — لا تغيّره** |
| **Amazon Polly — Hala / Zayd (Neural, ar-AE)** | ✅ خليجي + فصحى | ❌ AWS (نفس حسابك!) | بشرية، موثوقة، رسمية | 1M حرف neural/شهر مجاني + سنتات بعده · <500ms | **الأقرب لـ«ElevenLabs داخل AWS» — أنصح به كبديل رسمي** |
| **Nabra-82M** (Kokoro/StyleTTS2-Arabic، INT4 ~57MB) عبر **sherpa-onnx 2.x** | ✅ فصحى (MSA) — صوت واحد | ✅ **محلي 100% على السيرفر** | جيدة جداً (مو ElevenLabs) | Apache-2.0 · RTF ~0.66 حتى على Snapdragon 865 → يشتغل حقيقي على t4g.micro/small | **الاختيار الصحيح لـ"محلي ببلاش" — يتطلب تثبيت وتجربة يدوية** |
| **Piper `ar_JO-kareem-medium`** | ✅ أردني | ✅ محلي | متوسطة | خفيف جداً على ARM | احتياط أخف من Nabra — جودة أقل بوضوح |
| **XTTS v2 (Coqui)** | ✅ عربي + استنساخ صوتك | ✅ لكن ثقيل (~2GB، يحتاج 2-4 vCPU الفعلي) | **قريبة من ElevenLabs + استنساخ** | على micro: ثواني لكل جملة · يحتاج t4g.medium+ | ❌ خارج ميزانية $100 عملياً (≈$170+ على 6 أشهر) |
| **Kokoro-82M الأصلي** | ❌ **ما بيدعم عربي** | — | ممتازة للغات المدعومة | — | مرفوض هون — للإنجليزية ممتاز بس مش لجارفس |

**الخلاصة العملية بثلاث نقاط:**
1. **للمحادثات اليومية**: Edge TTS يضل الأساس — مافي بديل مجاني يعطي شامي بهالثمن (صفر).
2. **لو بدك كل شي "داخل AWS" بمعنى مشروع:** Polly (Hala/Zayd Arabic neural) = 15 دقيقة إعداد، بشري، وبيتدفع من نفس الرصيد (أول 12 شهر 1M حرف/شهر مجاني — استخدامك الشخصي 5-50k حرف/شهر → تقريباً $0). Polly بيدفع فقط من AWS من دون أي طرف ثالث — أحسن شي هالجهة.
3. **لو بدك "محلي 100% حتى لو السيرفر منقطع عن الإنترنت":** Nabra-82M + sherpa-onnx على نفس الـ EC2 — مجاني للأبد، جودة جيدة جداً، فصحى (مش شامية). التثبيت خطوة بخطوة تحت.

## 3) المعمارية الكاملة المقترحة على AWS (كل القطع — بلا عبوات مخفية)

```
أنت (تلفون/لابتوب) ──https──► https://<worker>/live  (Cloudflare Pages/Workers — مجاني دايم)
                                    │
                                    ▼
                         توكن LiveKit من /livekit-token (مجاني)
                                    │
                                    ▼
   ┌─────────────────  EC2 t4g.micro (Amazon Linux 2023)  ~$10/شهر  ─────────────────┐
   │  livekit-agent (Python) — شغال 24/7 بنظام systemd                               │
   │    ├─ STT  : Groq Whisper large-v3-turbo  (API مجاني — صفر استهلاك رصيد)        │
   │    ├─ عقل  : Coarena (Claude Fable 5.2)   (API مجاني $5/يوم — يظل مجاني دايماً)  │
   │    ├─ TTS  : Edge TTS (أساسي) أو Polly Hala/Zayd (AWS-داخلي) أو Nabra-82M (محلي) │
   │    └─ VAD  : Silero (محلي — صفر استهلاك)                                         │
   └──────────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
                         LiveKit Cloud (مشروعان مجانيان)
```

**حسابات الـ 6 أشهر على الرصيد (بالأسعار الحالية us-east-2 تقريباً):**

| القطعة | شهرياً | 6 أشهر |
|---|---|---|
| t4g.micro (Agent 24/7) | ~$6.1 | ~$37 |
| IP عام للسيرفر ($0.005/ساعة) | ~$3.65 | ~$22 |
| EBS 8–16GB gp3 | ~$0.7–1.3 | ~$5–8 |
| Polly (استخدام شخصي نموذجي) | ~$0–1 | ~$0–5 ✅ (1M حرف/شهر مجاني أول 12 شهر) |
| **المجموع المتوقع** | **~$10–12** | **~$65–72** من $100 — بهامش أمان مريح |

- لو لزم **t4g.small** (2GB): ≈ $12.3 + $3.65 + قرص ≈ $17/شهر → ~$101 على الفترة — عند الحد تماماً؛ لذلك ابدأ micro ولا ترفع إلا إذا Nabra ضغط الذاكرة.
- **XTTS/GPU/أي instance أكبر** = يكسر الرصيد خلال أسابيع. ممنوع.
- **بعد 2027-05-13**: Coarena وEdge TTS وLiveKit وGroq لا تتأثر (مو AWS). عندها انقل الـ Agent لجهازك أو Oracle Always Free — المعمارية نفسها، صفر تغيير كود.

## 4) تطبيق Nabra-82M (صوت عربي «محلي» حقيقي) — خطوات على السيرفر

> **تنبيه صادق:** ما قدرت أنزّل النموذج بالبيئة اللي بطور فيها (الوصول محدود لـ PyPI/GitHub فقط)، فما فعلت اختبار تشغيل فعلي — **الأوامر منشورة بالمصدر الرسمي (k2-fsa/sherpa-onnx issue #3897 + oddadmix/Nabra-82M-v0.1 على Hugging Face) وبقدر ما تغيّر إصدار sherpa-onnx تتغيّر الأعلام — راجع README النموذج أولاً.**

```bash
# على نفس سيرفر EC2 (بعد الخطوة 4 بدليل AWS_EC2_AR.md):
source .venv/bin/activate
pip install sherpa-onnx==1.13.6      # الإصدار المجرّب من مطور النموذج

# حمّل النموذج (مثال — من صفحة النموذج على Hugging Face):
#   oddadmix/Nabra-82M-v0.1  (الملف المكمّم INT8/INT4 — الأصغر أضبط للـ micro)

# الخدمة: sherpa-onnx-offline-tts مع:
#   --kokoro-model=nabra.int4.onnx   (أو حسب اسم الملف بصفحة النموذج)
#   --kokoro-voices=voices.bin       (إن وجد)
#   --kokoro-tokens=tokens.txt
#   --kokoro-data-dir=espeak-ng-data (من espeak-ng)
# ثم تغيّر agent.py: CLASS شريفة OfflineTtsKokoroModelConfig (pseudocode موثق بissue #3897)
```

**الترتيب المقترح للتجربة (لا تقفز):**
1. شغّل الوضع الحالي (Edge TTS) كامل ← تأكد المكالمة تشتغل 24/7.
2. جرّب Nabra يدوياً على السيرفر (شيفرة سطر واحد تولّد جملة) — إذا اشتغل RTF < 1 → ممتاز.
3. ثبّته كبديل داخل `agent.py` فقط إذا نجحت (2) **وبموافقتك** — تدخّل صوتي حي ما بأنفذ فيه بلا تجربة منك.
4. Audio-only comparison: سجّل نفس الجملة بالثلاثة (edge/polly/nabra) واستمع.

## 5) تطبيق Polly (خمس دقائق، بشري، موثوق) — بديل داخل AWS
```bash
# على نفس السيرفر — الصلاحيات بـ IAM role (لا مفاتيح بملفات):
# 1) IAM → Roles → EC2 → attache AmazonPollyReadOnlyAccess
# 2) على السيرفر:
pip install boto3
python3 - <<'EOF'
import boto3
polly = boto3.client("polly", region_name="us-east-2")
r = polly.synthesize_speech(Text="أهلاً دكتور، أنا جارفس — شو بدك نعمل اليوم؟",
                            VoiceId="Zayd",           # أو "Hala" للأنثى
                            Engine="neural",
                            LanguageCode="ar-AE",
                            OutputFormat="mp3")
open("/tmp/jarvis.mp3","wb").write(r["AudioStream"].read())
EOF
```
لاستخدامه **داخل الـ Agent** بدل Edge TTS: نفس نمط `EdgeTTSChunkedStream` بملف جديد `PollyTTS` — **بتطلبه وأنا أجهزه كامل بعد ما تتأكد** إنك بدك الصوت الخليجي بدل الشامي للصوت اللي بالسماعة.
