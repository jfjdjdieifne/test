# 📱 كيف تشغّل Arena على جارفس — دليل آيفون خطوة بخطوة (بالعربي المفهوم)

> هذا الدليل مكتوب لمين معه **آيفون فقط**، وما بيحبش التيرمنال. كل شي بيصير من **Safari**
> ومن **تيليجرام**. ما في ولا سطر أوامر لازم تكتبه إلا إذا حبيت.

---

## أول شي: فهم الفكرة بـ ٣٠ ثانية

- **جارفس** (البوت تبعتك على تيليجرام) شغال على Cloudflare — بيوصل تيليجرام ويقرر شو يعمل،
  بس **ما بيقدر يشغّل Python** ولا يفتح متصفح.
- **Arena** موقع، للوصول له بدنا "غرفة بايثون" صغيرة (اسمها **الجسر**) تفتح المتصفح وتحكي مع Arena.
- الجسر لازم يكون على **جهاز شغّال دايماً** — الآيفون ما بينفع يضل شغال ٢٤ ساعة،
  فمنستأجر "جهاز ببلاش" على النت (السحابة) ونشغّل الجسر عليه.
- بعد ما يشتغل الجسر، بتيليجرام بتقلّي: "هذا عنوانه، وهذا مفتاحه" — وبس. جارفس بيصير
  يستخدم Arena كعقل أساسي.

```
تيليجرام  →  جارفس (Cloudflare)  →  الجسر (بايثون على النت)  →  Arena
```

---

## الخطوة 0 — تأكد جارفس شغال حالياً (دقيقة)

1. افتح تيليجرام → بوت جارفس → اكتب `/start`.
2. لازم يرد عليك بقائمة الأوامر.

✅ إذا رد → كمّل. ❌ إذا ما رد → المشكلة بالبوت نفسه (توكن/نشر)، مش بهذا الدليل.

## 🅱️ الطريق B — Hugging Face Space (بلا بطاقة) ⭐

### 🚀 الأسهل: أنشئ الـ Space بضغطة زر من GitHub

هاي الطريقة ما بدها تنزيل ZIP ولا رفع ملفات، وكلها من Safari على الآيفون:

1. اعمل حساب Hugging Face وفعّل الإيميل: `https://huggingface.co/join`.
2. افتح `https://huggingface.co/settings/tokens` → **Create new token** → اختر **Write** → انسخ التوكن.
3. افتح مستودع GitHub → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**، وأضف:
   - الاسم `HF_TOKEN` والقيمة هي التوكن المنسوخ.
   - كررها باسم `BRIDGE_API_KEY` وقيمة مفتاح طويل من اختيارك، واحفظه بملاحظات الآيفون.
4. افتح تبويب **Actions** بالمستودع → **Deploy Arena Bridge to Hugging Face Space** → **Run workflow** → **Run workflow**.
5. انتظر علامة ✅ (أول بناء عادةً ٣–٧ دقائق)، ثم افتح التشغيل واضغط **Summary**. ستجد رابط الجسر وأوامر تيليجرام جاهزة.
6. أرسل للبوت، كل سطر لوحده:
   ```
   /arena url https://<اسمك>-jarvis-arena-bridge.hf.space
   /arena key <نفس BRIDGE_API_KEY>
   /arena test
   ```

> 🔒 لا ترسل `HF_TOKEN` ولا `BRIDGE_API_KEY` لأي شخص. الـ Space عام، لكن GitHub وHugging Face يحجبان قيم الأسرار.
>
> إذا ما ظهر تبويب **Actions** أو ما قدرت تضيف Secrets (مثلاً المستودع مش بحسابك)، استخدم الرفع اليدوي تحت. على iPhone قد تحتاج من قائمة Safari **طلب موقع ويب لسطح المكتب** حتى تظهر كل الأزرار.

### الرفع اليدوي (الخطة البديلة)

### B1) نزّل ملفات المشروع على الآيفون
1. افتح **Safari** → روح على: `https://github.com/jfjdjdieifne/test`
2. تأكد فوق إنك على الفرع: **`arena/a02addea-test`** (زر الفروع بجانب اسم الملفات).
3. اضغط الزر الأخضر **Code** → **Download ZIP**.
4. بيقولك Safari "هل تريد التنزيل؟" → **Download**.
5. افتح تطبيق **Files** (الملفات) → **التنزيلات** → اضغط على الملف `test-arena-a02addea-test.zip` مرة وحدة → بينفكّ لحاله (بيصير مجلد).

### B2) أنشئ حساب Hugging Face
1. Safari → `https://huggingface.co/join` → بريدك + كلمة سر → **Sign Up**.
2. فعّل الإيميل من صندوق الوارد.

### B3) أنشئ "Space" جديد
1. وأنت مسجّل، اضغط صورتك فوق يمين → **New Space**.
   (أو مباشرة: `https://huggingface.co/new-space`)
2. عبّي:
   - **Space name:** `jarvis-arena-bridge`
   - **License:** `mit` (أي شي)
   - **Select the Space SDK:** اختر **Docker**
   - **Docker template:** اختر **Blank**
   - **Hardware:** `CPU basic · 2 vCPU · 16GB · FREE`
   - **Visibility:** **Public** (المجاني لازم يكون عام — لا تحط كوكيز بالكود!)
3. اضغط **Create Space**.

### B4) ارفع ٤ ملفات (اسحب من Files)
من صفحة الـ Space: **Files** → **Add file** → **Upload files** → **choose files**:

| ارفع هذا الملف من مجلد التنزيلات | إلى الـ Space باسم |
|---|---|
| `arena-bridge/bridge.py` | `bridge.py` |
| `arena-bridge/requirements.txt` | `requirements.txt` |
| `arena-bridge/deploy/huggingface/Dockerfile` | `Dockerfile` |
| `arena-bridge/deploy/huggingface/README.md` | `README.md` |

بعد كل اختيار اضغط **Commit changes to main**.

> 💡 إذا رفع الـ README علّق: غير الـ front-matter بملف `deploy/huggingface/README.md`
> موجود فيه `sdk: docker` و`app_port: 7860` — لازم يضلوا زي ما هنن.

### B5) حط المفتاح (Secret)
1. من الـ Space: **Settings** → **Variables and secrets** → **New secret**.
2. **Name:** `BRIDGE_API_KEY`
3. **Value:** مفتاح طويل من عندك — مثال: `jarvis-arena-2026-Ahmed-x9k2`
   📝 **اكتبه بمكان** (ملاحظات الآيفون) لأنك رح تحتاجه بتيليجرام.
4. **Save**.

### B6) استنى البناء وجيب الرابط
1. صفحة الـ Space فيها تبويب **Logs** — استنى لين تشوف `Application startup complete`
   (أول مرة ٣–٧ دقائق).
2. الرابط شكله هيك (زر **⋮** → **Embed this Space** / أو من المتصفح):
   ```
   https://<اسم-حسابك>-jarvis-arena-bridge.hf.space
   ```
3. افتحه بتاب جديد وزيد `/health`:
   ```
   https://<اسم-حسابك>-jarvis-arena-bridge.hf.space/health
   ```
   ✅ لازم تشوف: `{"status":"ok","service":"jarvis-arena-bridge", ...}`

## 🅰️ الطريق A — Render (بديل أسرع، بس 0.5 جيجا)

1. Safari → `https://render.com` → **Get Started** → **GitHub** → اسمح للموقع.
2. **New +** → **Web Service**.
3. اختر المستودع `jfjdjdieifne/test` → **Connect**.
   (إذا ما ظهر: اضغط **Configure account** → اختر المستودع → **Save**.)
4. عبّي بالضبط:
   - **Name:** `jarvis-arena`
   - **Branch:** `arena/a02addea-test`  ← مهم! الكود بهذا الفرع
   - **Root Directory:** `arena-bridge`
   - **Runtime:** **Docker**
   - **Instance Type:** **Free**
5. **Environment Variables** → **Add**:
   - `BRIDGE_API_KEY` = مفتاح طويل من عندك (اكتبه!)
   - `DEFAULT_MODEL` = `auto`
6. **Create Web Service** → استنى **Logs** لين يكتب `Live`.
7. فوق الصفحة بيطلع الرابط: `https://jarvis-arena-xxxx.onrender.com`
   افتحه مع `/health` → لازم `status: ok`.

⚠️ الخطة المجانية 0.5 جيجا — محتمل ما يكفي متصفح Arena. إذا كل شي أحمر بخطوة الفحص،
روح على الطريق B.

## الخطوة الأخيرة — الربط من تيليجرام (بدون كمبيوتر!)

افتح جارفس بتيليجرام، وابعت **٣ رسائل** بالترتيب:

```
/arena url https://<اسم-حسابك>-jarvis-arena-bridge.hf.space
```
```
/arena key jarvis-arena-2026-Ahmed-x9k2
```
```
/arena test
```

**شنو معنى رد `/arena test`:**
- 🟢 محرك أخضر = Arena جاهز فعلاً. ✅ خلص — كل ردود جارفس صارت من Arena.
- 🔴 كلهم حمر = الجسر شغال بس ما قدر يوصل Arena (كوكيز/حماية). شوف "حل المشاكل" تحت.

جرّب بعدها:
```
/arena_ask اكتب لي ٣ أفكار منشورات لشركة ديكور بدبي
```
وكمان جرّب مهمة كاملة (جارفس رح يستخدم Arena كعقل + أدواته):
```
دور على ٣ شركات ديكور بالرياض وافحص مواقعهم وابعتلي التقرير
```

## التحكم اليومي (احفظ هذي الأوامر)

| أكتب | شو يصير |
|---|---|
| `/arena` | حالة الجسر + النموذج + هل هو أساسي |
| `/arena test` | فحص حقيقي لكل محرك (يقولك مين شغال) |
| `/arena primary` | يقلب: Arena أساس ↔ احتياطي |
| `/arena off` / `/arena on` | يوقف/يشغّل استخدام Arena فوراً |
| `/arena wake` | يفيّق الجسر إذا نام |
| `/arena models` | يعرض النماذج المتاحة |
| `/arena <اسم-نموذج>` | يثبّت نموذج معيّن |
| `/arena reset` | يمسح العنوان والمفتاح |
| `/arena setup` | يعيد هذا الشرح بتيليجرام |

## حل المشاكل (أهم جدول بالدليل)

| اللي تشوفه | المعنى | الحل |
|---|---|---|
| `/arena` يقول "مو مضبوط" | ما وصلك رابط ولا مفتاح | أعد `/arena url ...` و`/arena key ...` |
| `/health` ما يفتح / صفحة بيضا | البناء لسا شغال أو وقع | HF: تبويب **Logs** · Render: **Logs**. أعِد **Restart** |
| `/arena test` كلهم 🔴 | الجسر شغال بس Arena رافض | انتظر ١٠ دقائق وأعد، أو `/arena wake`، وإذا ضل: أعد بناء الـ Space (Factory rebuild) |
| 🔴 LMArenaBridge فقط | ما في جسر محلي (طبيعي) | مو مشكلة — gpt4free هو اللي بيشتغل |
| ⚪️ gpt4free غير مثبّت | `requirements.txt` ما اترفع صح | أعد رفع `requirements.txt` + **Factory rebuild** |
| الجسر ينام ويعطي 502 | استضافة بتنوّم الخدمة | Keep-alive يشتغل تلقائياً لعناوين `hf.space` و`onrender.com` — تأكد `/arena` يقول Keep-alive مفعّل |
| الردود صارت بطيئة | Arena يفتح متصفح (١٠–٢٥ ثانية) | طبيعي. بتحب أسرع؟ `/arena primary` للاحتياطي، أو `/arena off` |
| حساب Arena محظور/كوكيز | استخدام آلي كثير | جدّد الجلسة، أو قلل الاستخدام |

## أسئلة سريعة

**هل لازم أخلّي الآيفون مفتوح؟** لا. الجسر على السحابة، والآيفون بس للتحكم بتيليجرام.

**هل بيكلّف شي؟** الطريق B و A مجانيين بلا بطاقة. Oracle بيطلب بطاقة للتحقق فقط (بدون خصم).

**بيوقف جارفس إذا وقع الجسر؟** لا. جارفس يرجّع تلقائياً على Gemini/Mistral/Groq/OpenRouter
ويضل يرد عليك — بس الردود ما تكون من Arena.

**من وين أعرف إنه فعلاً Arena يلي رد؟** `/arena_ask سؤال` — أول سطر بالرد فيه اسم النموذج.
وكمان `/arena test` يوري نتيجة كل محرك.

**بدي أرجّع كل شي زي قبل؟** `/arena off` — فوري، بدون ما تمسح شي.

## أمان — ٣ قواعد بس
1. **لا ترسل** `BRIDGE_API_KEY` ولا رابط الجسر لأي حد (مع توكين البوت = يتحكم ببوتك).
2. الـ Space المجاني **عام** — الكود ظاهر. عشان هيك الكوكيز ما تنحط بالكود أبداً (Secrets فقط).
3. الاستخدام الآلي لـ Arena قد يخالف شروطهم وقد يُحظر الحساب — على مسؤوليتك وحسابك الشخصي.
