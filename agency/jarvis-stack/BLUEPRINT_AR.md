### ب) الصوت الحقيقي والاتصال الثنائي
1. **المحادثة الحية المباشرة (تتكلم ويقاطعك/تقاطعه بزمن استجابة ~300ms):**
   - استخدم **Gemini Live API** عبر WebSocket (`wss://generativelanguage.googleapis.com/...BidiGenerateContent`) مع نموذج `gemini-2.5-flash-native-audio` أو `gemini-3.8-live`.
   - يدعم **97 لغة منها العربية**، ويستدعي الأدوات (Function Calling) أثناء الكلام، وله مثال مفتوح المصدر رسمي من جوجل بالمتصفح مباشرة:
     `https://github.com/google-gemini/gemini-live-api-examples/tree/main/gemini-live-ephemeral-tokens-websocket`

2. **الاستقبال عبر رقم هاتف حقيقي (تتصل عليه من جوالك بـ $0):**
   - **LiveKit Cloud (خطة Build):** `$0/شهر` بدون بطاقة بنكية.
   - تشمل: **1 رقم هاتف أمريكي مجاني (US local)** + **50 دقيقة واردة/شهر** + **1,000 دقيقة جلسة وكيل** + **$2.50 رصيد inference**.
   - **القيد المهم:** الرقم المجاني **للمكالمات الواردة فقط (Inbound only)**. لإطلاق مكالمات صادرة لأرقام شريحة عادية يلزم SIP Trunk مدفوع مثل Telnyx/Twilio (~$0.015/دقيقة).

3. **كيف تجعل جارفس "يرن عليك" فعلاً بتكلفة $0؟**
   - **الطريقة المجانية الأسرع (مضمنة داخل `jarvis_telegram_agent.py` هنا!):**
     1. افتح تيليجرام وأرسل `/start` للبوت `@CallMeBot_txtbot` (لإعطاء الإذن لمرة واحدة).
     2. ضع اسم مستخدمك في `.env` تحت `CALLMEBOT_TELEGRAM_USER=@yourname`.
     3. الآن عند أي تذكير عاجل أو أمر `"رن عليّ"`، يستدعي جارفس:
        `http://api.callmebot.com/start.php?user=@yourname&text=...`
        فيرن هاتفك **مكالمة تيليجرام صوتية حية** وتسمع الرسالة بالصوت (الحد المجاني: 256 حرف لكل مكالمة. ملاحظة موثقة من CallMeBot: iOS أحياناً فيه خلل صامت بـ VoIP على تيليجرام، بينما Android وDesktop يعملان بشكل طبيعي).
   - **للرسائل الصوتية ثنائية الاتجاه في أي هاتف (iOS + Android بلا أي أعطال):**
     - أرسل رسالة صوتية لبوتك على تيليجرام ← يفهمها فوراً بـ Groq Whisper ← ينفذ أدواتك ← ويرد عليك بنص + رسالة صوتية عربية طبيعية بصوت `ar-AE-HamdanNeural` عبر `edge-tts`.

## 3. خطوات التشغيل الفوري لهذا المجلد (`jarvis-stack/`) خلال 10 دقائق

### الخطوة 1: تجهيز المفاتيح المجانية (لا بطاقة بنكية)
1. افتح تيليجرام ← ابحث عن `@BotFather` ← أرسل `/newbot` ← احفظ `TELEGRAM_BOT_TOKEN`.
2. في تيليجرام ← ابحث عن `@userinfobot` ← أرسل `/start` ← احفظ رقم الـ ID الخاص بك (`ALLOWED_TELEGRAM_ID`) حتى لا يتحكم غيرك بالبوت.
3. احصل على مفتاح مجاني (يفضل الاثنين أو الثلاثة للتبديل التلقائي):
   - Gemini: `https://aistudio.google.com/apikey`
   - Groq (مهم للصوت + السرعة): `https://console.groq.com/keys`
   - OpenRouter: `https://openrouter.ai/keys`

### الخطوة 2: تشغيل وكيل جارفس الصوتي والتنفيذي (`jarvis_telegram_agent.py`)
```bash
cd agency/jarvis-stack
cp .env.example .env
# عدّل .env وضع التوكن والمفاتيح
pip install -r requirements.txt
python3 jarvis_telegram_agent.py
```
