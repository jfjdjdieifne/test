# جارفس CEO — مديرك التنفيذي على تيليجرام

بوت تيليجرام شخصي يحكي باللهجة الشامية، يدير فريق وكلاء (كل وكيل = فابل 5.2 + شخصية)،
يشتغل على Excel، يراقب مواقعك، وبيقدر **يعدّل نفسه** من الشات.

## التشغيل على السيرفر (مرة واحدة)

```bash
git clone <هذا الريبو> ~/jarvis-source
mkdir -p ~/jarvis-ceo && cp ~/jarvis-source/jarvis-ceo/* ~/jarvis-ceo/ && cd ~/jarvis-ceo
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
python3 -m unittest test_agent   # لازم تطلع OK
```

## الأسرار (مرة واحدة)

ملف `~/jarvis-ceo.env` بصلاحيات 600 — **ولا ترسله بأي شات**:

```bash
TELEGRAM_BOT_TOKEN=<توكن بوت jarvis v1>
COARENA_BASE_URL=https://coarena.ai/api/v1
COARENA_MODEL=claude-fable-5-2
COARENA_API_KEY=<مفتاح Coarena>
GEMINI_API_KEY=<نفس مفتاح Gemini اللي بالتجارب>
DAILY_TOKEN_CAP=200000
CEO_CHAT_ID=<رقم محادثتك مع البوت>   # اختياري: أول من يحكي مع البوت بينحصر فيه

# GitHub — Fine-grained PAT من github.com/settings/tokens (صلاحية Contents + Pull requests + Administration)
GITHUB_TOKEN=<توكن GitHub>
GITHUB_OWNER=jfjdjdieifne

# جيميل — App Password من myaccount.google.com/apppasswords (حط خطوتين تفعيل أولاً)
GMAIL_ADDRESS=<ايميلك>
GMAIL_APP_PASSWORD=<كلمة مرور التطبيق>

# X (تويتر) — من developer.x.com (اختياري)
X_API_KEY= / X_API_SECRET= / X_ACCESS_TOKEN= / X_ACCESS_SECRET=

# Meta — انستغرام Business مربوط بصفحة Facebook (الأصعب — بياخد خطوة إعداد)
META_PAGE_ID= / META_PAGE_TOKEN= / META_IG_USER_ID=
```

```bash
chmod 600 ~/jarvis-ceo.env
```

## التشغيل الدائم (systemd)

```bash
sed -e "s/REPLACE_USER/$USER/g" -e "s/REPLACE_HOME/$HOME/g" jarvis-ceo.service > /tmp/jarvis-ceo.service
sudo cp /tmp/jarvis-ceo.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now jarvis-ceo
sudo systemctl status jarvis-ceo
```

## خريطة القادم (ولمن يخلص حسابك)

| المرحلة | شو بدها منك | الوضع |
|---|---|---|
| استضافة مواقع فورية (Vercel / Cloudflare Pages) | حساب مجاني + توكن | الكود جاهز لما تحط المفتاح — ما بتأخره اليوم عشان خاطري |
| بوابة دفع (Lemon Squeezy / Stripe) | حساب بنكي منك + موافقة فتح الحساب | جارفس ما بيفتح حساب دفع لحاله — هالشي ممنوع قانونياً |
| المبيعات الباردة الضخمة (سبام) | **ما بنعمله — سبام وبيحرق الدومين تبعك** | النسخة الشرعية: جارفس بصيغلك مسودة شخصية + بموافقة بضغطة ابعثها |
| تتبع CRM تلقائي من الإيميل | جيميل مربوط (الخطوة 2) | بيجي بعد استقرار جيميل |

**ذكاء حقيقي بدون تهويل**: جارفس بيلاقي ويرشح وبيوظف ويشحن المنتج — بس الزر الأخير (دفع/نشر جماعي/فتح حسابات) بتضل عندك، لأنه حسابك وهويتك.

## هبّة «كلشي» (الجولة الثانية)

| الأمر بالتيليجرام | شو بيعمل |
|---|---|
| «ربط الجيميل» / «ربط GitHub» … | جارفس بعطيلك الخطوات خطوة خطوة — بلا ما تتعلم شي |
| «شو لازم اضيف» | لستة بكل الناقص وشو اسمه بالضبط |
| `احفظ مفتاح GITHUB_TOKEN=...` | بينحفظ بالمكان السري + **رسالتك تنمسح** تلقائياً |
| «احفظ عني: …» / «وش تعرف عني» | ملف شخصي دائم — بيعرفك أكثر بكل محادثة |
| «ذكرني 9:00 …» / «كل يوم 9:00 …» / «كل أسبوع الجمعة 10:30 …» | تذكيرات بتنفع حتى «كل أسبوع» |
| «تذكيراتي» / «شيل تذكير 3» | إدارة التذكيرات |
| «صورة: <وصف>» | صورة مجانية بالتوليد (Pollinations) — تنفع برمضانات X/IG |
| «ابحث بالمشروع عن <كلمة>» / «اقرأ <ملف>» / «حدث فهمك» | عيون جارفس على ملفاتنا |
| أي سؤال «نقدر نعمل X بمشروعنا؟» | بيقرأ المشروع وبيفهمه قبل الجواب |

## ضمانات بيضل عليها مهما اشتد الذكاء

- **سقف إنفاق يومي** `DAILY_TOKEN_CAP` (افتراضي 200k توكن) — فابل ما بينحرق الـ $55 بحلقة مجنونة.
- **التعديل الذاتي**: نسخة احتياطية → تعديل → `py_compile` + كل الاختبارات → إذا فشل أي شي يرجع للنسخة تلقائياً → `تراجع` بأي وقت.
- **ما بيلمس** `~/jarvis-ceo.env` ولا أي شي خارج مجلد jarvis-ceo.
- **قرارات مالية/خارجية**: اقتراحات فقط — التنفيذ بموافقتك الصريحة.

## ⚡ رعد — وكيل التحليل الورقي (ورقي 100%)

مشروع مستقل داخل البوت: يراقب كريبتو عبر Binance public API (بلا مفتاح، مجاني)، يشتغل بفلسفة «الرفض قبل الاقتراح» — ما توصلك بطاقة إلا إذا المرشح اجتاز — وكل بطاقة تتقرر بالدفتر (`~/jarvis-raad.db`) وبتتثبّت بعدها. أبداً لا ينفذ صفقة حقيقية؛ التنفيذ بفلوس حقيقية محتاج ✅ صريح منك لكل صفقة.

### التنصيب — أمر واحد
```
cd ~/jarvis-ceo && git pull origin arena/e3e2c397-test && bash raad_install.sh
```
التنصيب: يعتمد `.venv` إذا موجود، يركّب الكرون (فحص الدفتر كل 6 ساعات + مراجعة ليلية 01:30 UTC = 03:30 بتوقيت سوريا/فلسطين + تقرير صباحي 06:05 UTC)، ثم يرسل رسالة تفعيل تيليجرام + فحص Coarena (`COARENA_BASE_URL` / `COARENA_API_KEY` / `COARENA_MODEL` — نفس اللي عند جارفس).

### شو بيشتغل لحاله
- **تقرير صباحي على تيليجرام**: نظام BTC/ATR%/EMA + إحصائيات الدفتر + 3 عناوين أخبار (إذا TAVILY_API_KEY موجود) + موقف رعد.
- **بطاقة ورقي** (لو المرشح اجتاز بس — تقاطع EMA20/50 + حجم عالي + نظام مناسب): الدخول/الوقف/الهدف/الثقة + رأي العقل (استدعاء واحد على الأكثر لكل بطاقة).
- **مراجعة ليلية 01:30 UTC**: قرار الصفقات المفتوحة، expectancy/PF/maxDD/معايرة الثقة، كتابة الدرس بـ `PLAYBOOK.md` (commit محلي فقط — لا دفع تلقائي)، وتطبيق **تعديل واحد فقط** من قائمة بيضاء مغلقة (إيقاف طوارئ تلقائي أو تعليم Bucket منحرفة). الكود مستحيل يتعدّل تلقائياً.

### التحديث التلقائي 🔄
`auto_update.sh` (بيركّبه `raad_install.sh` تلقائياً مع الكرون): كل ١٠ دقائق بيسأل GitHub; لو الفرع `arena/e3e2c397-test` تغيّر، بيطلع Backup (بدون `.venv`) ← ينزل النسخة الجديدة ← يحطها مكانها ← `systemctl restart` ← **يفحص إن البوت رجع كله يشتغل; لو فشل، بيرجع للنسخة القديمة وحده ويرسلك خبر.** `.venv` ما تُلمس — الحزم الجديدة بس مع «تحديث» يدوي.

### حدوده (واضحة ومقصودة)
- ورقي بحت — ما حدا بدفع ولا يشتري ولا يبيع.
- ما في «توصية مضمونة»؛ والدفتري هو الحكم ومن فترة ٣٠+ صفقة.
- الكرون بتوقيت السيرفر (UTC افتراضياً). للتوقييت: `crontab -e`.
- لإضافة استراتيجيتك: ملف نصي بـ `raad_strategies/` (شوف `اقرأ_اولاً_كيف.txt` هناك).

### أوامر يدوية
```
python3 raad.py once      # فحص فوري — قد يطلع silence
python3 raad.py resolve   # قرار الصفقات المفتوحة
python3 raad.py report    # التقرير الصباحي هلق
python3 raad.py backtest BTCUSDT 1000   # اختبار رجعي للمرشح المدمج
python3 raad.py resume    # إلغاء إيقاف الطوارئ التلقائي
```
إلغاء كامل لرعد: `crontab -l | grep -v raad | crontab -` — والدفتر بيظل محفوظ.

## 📞 المكالمة الصوتية (LiveKit + Gemini Live)

زر «📞 المكالمة» بيتظهر بكل رسالة من البوت. **كبسة واحدة** → المتصفح يفتح المكالمة مباشرة ولاقي جارفس عم يرحب فيك حسب وقت اليوم (صباح/مساء/سهرة) مع دفء — بيسمع مزاجك وضجة الخلفية وبيعلّق عليهم (Gemini Live Affective Dialog).

### الإعداد (مرة واحدة)
1. حساب LiveKit Cloud مجاني: `cloud.livekit.io` ← أنشئ مشروع ← Settings ← Keys ← انسخ **API Key** و**Secret** وعنوان wss
2. على السيرفر احفظ بملف `~/jarvis-ceo.env`:
   ```bash
   LIVEKIT_URL=wss://<مشروعك>.livekit.cloud
   LIVEKIT_API_KEY=API...
   LIVEKIT_API_SECRET=...
   ```
3. ثبّت الاعتماديات والخدمة:
   ```bash
   cd ~/jarvis-ceo && .venv/bin/pip install livekit-agents livekit-plugins-google livekit-api
   sudo cp jarvis-voice.service /etc/systemd/system/jarvis-voice.service
   sudo systemctl daemon-reload && sudo systemctl enable --now jarvis-voice
   ```
4. الصوت: الوكالة بتجيب مفتاح Gemini لحالها (`GEMINI_API_KEY` أو أول مفتاح من `GEMINI_TTS_API_KEYS`).
   اختياري: `GEMINI_LIVE_VOICE=Charon|Puck|Fenrir|Aoede...` و `GEMINI_LIVE_MODEL=...`

### بالمكالمة
- «مرحبا» ← بيرحب فيك حسب الساعة والجو
- أي سؤال/طلب ← لازم يستجب مباشرة أو «هلأ بشوف» ويرد
- «احفظ: مكان الاجتماع يوم الهلا» ← بينحفظ بالمذكرة
- «احفظ مفتاح TAVILY_API_KEY=...» ← بينحفظ بالمكان السري (ما بيطبع القيمة)
- «خلص» / «روح» / «سكر» / «باي» ← المكالمة بتسكر لحالها
- **واجهة الاتصال الخاصة بجارفس** (`callpage/index.html`) — صوت فقط بدون كاميرا، أزرار مفيدة فقط (ميكروفون / صوت جارفس / ملخص)، والوكيل نفسه بفتح البطاقات (صور/مواقع/قوائم/نص) ويسكرها بضغطة «سكر».
  - تنزل على **Cloudflare Pages** مجاني بدون بطاقات ولا سيرفر ولا دومين خاص: نسخ الملف → dash.cloudflare.com ← Workers & Pages ← Create ← Upload assets ← رفع المجلد → بتصير `https://<اسم>.pages.dev`
  - بعدها اضف سطر واحد بـ `~/jarvis-ceo.env`: `CEO_MEET_URL=https://<اسم>.pages.dev/?liveKitUrl={url}&token={token}`
  - الزر «📞 المكالمة» ثابت أسفل محادثة البوت (لوحة تيليجرام) — كبسة، ثم «🎙️ افتح المكالمة الآن»، وانت داخل.
